# План: `.one` для `Slot` и `CallerWithPlugins`

## Общая идея

Добавляем короткий путь для случаев, когда пользователь ожидает ровно один доступный вызываемый объект у слота или у выборки плагинов. Свойство `.one` будет возвращать `CallerWithPlugins`, если разрешение однозначно: есть ровно один плагин или, при отсутствии плагинов, у слота есть непустое тело, которое сработает как fallback. Если разрешение неоднозначно или невозможно, `.one` поднимает `OneResolutionError` с сообщением, различающим полный слот и выборку.

## Кратко

- Работаем строго по TDD: сначала добавляем падающие рантайм-тесты и тесты типизации, затем реализацию.
- `.one` будет вычисляемым свойством только для чтения, а не методом.
- `.one` возвращает объект `CallerWithPlugins`.
- `OneResolutionError` добавляем в `pristan.errors`; из корневого `pristan` не экспортируем.
- Каждый добавляемый тест и каждый изменяемый тест обязан иметь докстрингу в стиле существующих тестов: первая строка кратко описывает общую идею проверки, а следующие строки добавляются там, где нужно объяснить фиксируемое поведение, порядок действий и способ проверки.

## Изменения API и реализации

- Добавить `OneResolutionError` как прямого наследника `PristanException`.
- Добавить свойство только для чтения `CallerWithPlugins.one`:
  - если `bool(self)` ложен, поднять `OneResolutionError` с сообщением `Selection from slot "slot_name" has no selected plugins and the slot body is empty.`;
  - если `len(self) > 1`, поднять `OneResolutionError` с сообщением `Selection from slot "slot_name" has N selected plugins, so .one cannot choose one.`;
  - иначе вернуть `self`.
- Добавить свойство только для чтения `Slot.one`:
  - при каждом доступе вызвать `self._load_entrypoints()`;
  - создать новый неглубокий снимок `CallerWithPlugins(self.caller, list(self.plugins.plugins))`;
  - если `bool(snapshot)` ложен, поднять `OneResolutionError` с сообщением `Slot "slot_name" has no registered plugins and its body is empty.`;
  - если `len(snapshot) > 1`, поднять `OneResolutionError` с сообщением `Slot "slot_name" has N registered plugins, so .one cannot choose one.`;
  - иначе вернуть снимок.
- Реализовать `.one` как обычный `@property` без setter/deleter. Попытки присвоить и удалить `.one` у `Slot` и `CallerWithPlugins` должны давать стандартный `AttributeError` от `property`, не создавать теневой атрибут и не менять последующее чтение `.one`.
- Обновить типы и публичные протоколы:
  - у `Slot` и выборок должен быть доступен `.one`;
  - у протоколов `.one` возвращает тип выборки;
  - у выборки, полученной через публичный API, `.one` сохраняет тип этой выборки.

## План тестирования

### Общие требования

- Каждый добавляемый тест и каждый изменяемый тест получает докстрингу.
- Докстринги пишутся в стилистике существующих тестов: первая строка кратко описывает общую идею проверки; если контракт неочевиден, ниже добавляется пояснение поведения, которое фиксирует тест, и способа, которым тест это проверяет.
- Тесты, не проверяющие загрузку точек входа, изолируются от внешних точек входа.
- Все проверки `OneResolutionError` проверяют и тип исключения, и точный текст через `pytest.raises(..., match=match(...))`, как в существующих тестах.
- Существующие матричные тесты расширяем строками для `.one`, не создавая дублирующих тестов.
- В тестах типизации сценарии с современными встроенными generic-аннотациями `list[...]` и `dict[...]` выполняются только под `skipif(sys.version_info < (3, 9))`. Для каждого такого типизационного теста должна быть зеркальная версия на старых аннотациях `typing.List[...]` и `typing.Dict[...]`, которая работает на Python 3.8. Обычные рантайм-тесты для различий `list`/`List` и `dict`/`Dict` должны использовать уже существующие фикстуры по аналогии с текущими тестами.

## Допущения

- Снимок, возвращаемый `Slot.one`, отделяет список плагинов от родителя, но не копирует сами объекты плагинов.
- Резервное тело слота определяется только существующей машинерией `SlotCaller` и `SlotCodeRepresenter`; новая логика `.one` не добавляет отдельные эвристики определения пустого тела.
- `.one` не выполняет плагины и не выполняет тело слота при чтении свойства.
- `Slot.one` вызывает загрузку точек входа сам; `slot['name'].one` и `slot.pop('name').one` получают уже созданную выборку после загрузки, выполненной в `__getitem__` или `pop`.
- `.one` у уже созданного `CallerWithPlugins` дополнительную загрузку точек входа не выполняет.
